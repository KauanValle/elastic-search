# 🔍 Projeto Elasticsearch com Docker Compose

Este projeto tem como objetivo iniciar um contêiner do **Elasticsearch** de forma rápida e simplificada utilizando **Docker Compose**.

## 🧱 Estrutura

A estrutura do projeto é minimalista e contém apenas o arquivo `docker-compose.yml`, responsável por configurar e subir o serviço do Elasticsearch.

## ▶️ Como executar

1. Certifique-se de ter o Docker e o Docker Compose instalados.
2. No terminal, navegue até a pasta do projeto.
3. Execute o seguinte comando:

```bash
docker-compose up -d
